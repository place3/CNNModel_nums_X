# CNNModel_nums_X

Учебный проект на PyTorch для классификации рукописных оценок **0, 1, 2, 3, 4 и X**. На входе — изображение отдельного символа 28×28 в оттенках серого, на выходе — шесть оценок классов. Метка `5` обозначает `X`.

Проект связан с [RateScaner](https://github.com/place3/RateScaner): здесь находятся эксперименты обучения и данные, а RateScaner выделяет ячейки протокола, запускает распознавание и формирует результаты. Модель не распознаёт страницу целиком.

## Что реализовано

- CNN: два блока Conv2d → ReLU → MaxPool, Dropout и два полносвязных слоя.
- Обучение на цифрах MNIST 0–4 и собственных изображениях X.
- Аугментации X, взвешенная выборка, Adam и CrossEntropyLoss.
- Scheduler, early stopping и сохранение лучших весов.
- Вывод confusion matrix и метрик по классам в консоль.

## Использование весов

Для демонстрации распознавания следуйте инструкциям в [RateScaner](https://github.com/place3/RateScaner): там подготовлены CLI, примеры протоколов и проверки. Архитектура совместима с используемыми там весами. Файлы `.pth` и `.ckpt` содержат `state_dict`, а не полное состояние для продолжения обучения.

## Повторение обучения

Запуск обучения в чистом окружении пока не воспроизведён. Основной сценарий использует `torch`, `torchvision`, `numpy`, `Pillow`, `scikit-learn` и импортирует `pandas`. Проверенный набор версий зависимостей ещё не зафиксирован.

Перед `python CNNModel1.py` нужно адаптировать абсолютные пути Windows: `DATA_PATH`, `MODEL_STORE_PATH`, `X_DATASET_PATH` и пути проверочных X. Каталог моделей должен существовать заранее: лучшие веса сохраняются до создания каталога в конце сценария. Обучение может скачать MNIST и записывает модели; сохраните отдельную копию нужных весов.

`x_gener.py` и старые сценарии подготовки данных выполняют операции при импорте. Генератор записывает изображения под существующими именами; импортировать его как библиотеку пока не следует.

## Ограничения текущего эксперимента

- Рукописные обучающие X — светлые на тёмном фоне, синтетические проверочные — преимущественно тёмные на светлом. Проверочная подготовка не выравнивает эту разницу.
- Набор `test` используется для выбора весов и early stopping. По роли это validation; независимая итоговая оценка не подготовлена.
- `sample_weights[5] *= 2` изменяет вес одного примера, а не класса X. Перед новым обучением это нужно исправить.
- Среди 1000 синтетических файлов — 907 уникальных по SHA256. Файловые совпадения между двумя папками X не найдены; это не проверка независимости исходных страниц.
- Конфигурация, состав выборок и метрики не сохраняются вместе с весами. Связь графика с конкретными весами не подтверждена.
- Тестов и CI пока нет. Точность на независимой выборке не установлена.

Дальнейшая работа: переносимая конфигурация, исправление sampler, единая подготовка изображений, разделение данных по исходным страницам и воспроизводимая оценка каждого класса. Текущие веса и материалы сохранены; переобучение в рамках оформления не выполнялось.
